# Research sources and independent projects

Studied as **inspiration and authoritative methodology**. No code, rulepacks or branding copied. Refer to original documentation and licenses before using a tool or republishing content.

## Standards

- [OWASP ASVS 5.0](https://asvs.owasp.org/) — application security verification controls.
- [OWASP Top 10:2025](https://top10.owasp.org/2025/0x00_2025-Introduction/) — web application risks.
- [OWASP API Security Top 10:2023](https://owasp.org/API-Security/) — BOLA and API authorization.
- [OWASP MASVS](https://mas.owasp.org/MASVS/) and [MASTG](https://github.com/OWASP/owasp-mastg) — mobile assurance.
- [OWASP WSTG](https://github.com/OWASP/wstg) and [Cheat Sheet Series](https://github.com/OWASP/CheatSheetSeries).
- [MITRE CWE](https://cwe.mitre.org/) and [NIST SSDF SP 800-218](https://csrc.nist.gov/pubs/sp/800/218/final).
- [OpenSSF Scorecard](https://github.com/ossf/scorecard), [SARIF 2.1.0](https://docs.oasis-open.org/sarif/sarif/v2.1.0/sarif-v2.1.0.html).

## Public open-source design references

- [Semgrep](https://github.com/semgrep/semgrep) — rule-based multi-language static review.
- [GitHub CodeQL](https://github.com/github/codeql) — semantic source analysis.
- [Gitleaks](https://github.com/gitleaks/gitleaks) — secret scanning.
- [Trivy](https://github.com/aquasecurity/trivy) — dependencies, images and misconfigurations.
- [OSV-Scanner](https://github.com/google/osv-scanner) — dependency advisory checks.
- [Checkov](https://github.com/bridgecrewio/checkov) — IaC review.
- [ZAP](https://github.com/zaproxy/zaproxy) — authorized web security testing.
- [MobSF](https://github.com/MobSF/Mobile-Security-Framework-MobSF) — mobile assessments.
- [Bandit](https://github.com/PyCQA/bandit) — Python security checks.
- [OpenSSF Scorecard](https://github.com/ossf/scorecard) — OSS supply-chain posture.

**Important:** Cross-language source review and runtime validation require adapters, relevant parsers and experts. ASM v0.1 does not bundle or run those tools.
