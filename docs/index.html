REVIEW PIPELINE

01 / DISCOVER

فهم المشروع

تحديد اللغات، الإطار البرمجي، تدفقات البيانات والصلاحيات وحدود الثقة.

02 / ANALYZE

الفحص والمراجعة

جمع إشارات آلية ومراجعة المنطق والتهيئة، مع أدوات إضافية عند توفرها.

03 / TRIAGE

التحقق والتصنيف

تمييز الثغرات المثبتة عن الاشتباه، مع خطورة وأدلة ومستوى ثقة.

04 / REMEDIATE

العلاج والاختبار

شرح الإصلاح ومقترحات الاختبارات دون تغيير كود المشروع تلقائيًا.
